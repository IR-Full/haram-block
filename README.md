# Block Haram

Расширение для Chromium-браузеров (Chrome, Edge, Brave, Opera, Яндекс), которое блокирует сайты для взрослых.
Работает локально, без телеметрии и без кнопки отключения.

## Как это работает

```
Запрос ──► declarativeNetRequest (движок браузера, без JS)
              ├─ документ / iframe  → redirect на blocked.html
              └─ картинки, видео, скрипты с адалт-CDN → block
```

- **~535 000 доменов** из четырёх проверенных источников ([THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)).
- Правило DNR с `requestDomains` вмещает тысячи доменов вместе с поддоменами: весь список занимает ~214 правил.
  Проверку выполняет сам браузер в сетевом стеке, поэтому service worker не просыпается и на каждый запрос не тратится ни одной миллисекунды JS.
- Страница блокировки показывает аят 24:30 и считает попытки (счётчик хранится только в `chrome.storage.local`).

### Безопасный поиск

Второй набор правил (`public/rules/safesearch.json`, генерируется из [`tools/build-lists/safesearch.ts`](tools/build-lists/safesearch.ts)) принудительно включает строгий режим:

| Поисковик     | Как                                                    |
| ------------- | ------------------------------------------------------ |
| Google        | `safe=active` на всех доменах Google                   |
| Bing          | `adlt=strict`                                          |
| DuckDuckGo    | `kp=1`                                                 |
| Yandex, ya.ru | `family=yes`                                           |
| Brave Search  | `safesearch=strict`                                    |
| Yahoo         | `vm=r`                                                 |
| Startpage     | `qadf=heavy`                                           |
| YouTube       | заголовок `YouTube-Restrict: Strict` (Restricted Mode) |

Параметр добавляется внутренним редиректом Chrome ещё до отправки запроса, только на страницах результатов поиска.
Явный `safe=off` перезаписывается. Если параметр уже стоит, правило не срабатывает, так что редиректа по кругу нет (это проверяют e2e-тесты).
Что именно фильтрует сам поисковик по этим параметрам, стоит периодически проверять вручную, особенно в Yandex, Yahoo и Startpage.

## Установка (без Chrome Web Store)

```bash
npm ci
npm run build
```

Дальше откройте `chrome://extensions`, включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите `.output/chrome-mv3`.
Затем в «Сведениях» расширения включите «Разрешить использование в режиме инкогнито».

## Разработка

| Команда                 | Что делает                                                            |
| ----------------------- | --------------------------------------------------------------------- |
| `npm run dev`           | Chrome с расширением и HMR                                            |
| `npm run build`         | Сборка списков и расширения в `.output/chrome-mv3`                    |
| `npm run zip`           | Архив для Chrome Web Store                                            |
| `npm run lists`         | Пересобрать правила (скачивания кэшируются на 12 ч)                   |
| `npm run lists:refresh` | То же, но с принудительной перезагрузкой источников                   |
| `npm run lists:report`  | Какие сайты из топ-20k Tranco блокируются (поиск ложных срабатываний) |
| `npm run check`         | typecheck + lint + format + юнит-тесты                                |
| `npm run test:e2e`      | Playwright: настоящий Chromium с расширением, весь трафик локальный   |

### Сборщик списков — `tools/build-lists/`

1. Скачивает источники (`sources.ts`); если скачанный список меньше `minEntries`, источник сломан и сборка падает.
2. Нормализует записи (`normalize.ts`): punycode, отбрасывает IP-адреса, неизвестные TLD и публичные суффиксы вроде `blogspot.com` или `github.io`.
3. Вычитает `allowlist.txt`, где перечислены мейнстрим-платформы и проверенные ложные срабатывания. Поддомены из allowlist остаются заблокированными.
4. Схлопывает поддомены, если в списке уже есть родительский домен.
5. Проверяет, что все домены из `must-block.txt` покрыты.
6. Пишет `public/rules/adult.json` и `public/rules/meta.json` (оба генерируются и в git не хранятся).

Нашли ложное срабатывание? Добавьте домен в `allowlist.txt` с комментарием и выполните `npm run lists`.

## Публикация в Chrome Web Store

Регистрация разработчика — **разовый взнос $5**, дальше публикация бесплатная.
Именно публикация в CWS позволяет в Windows закрепить расширение политикой `ExtensionInstallForcelist`, чтобы его нельзя было удалить или выключить.
Для расширений не из стора эта политика работает только на компьютерах в домене.
